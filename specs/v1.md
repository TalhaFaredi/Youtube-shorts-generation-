# YouTube Extractor — Specs (v1)

## Purpose
A small local web app. The user pastes a YouTube link and gets back the video's
transcript and a set of frames (screenshots) extracted from the video.

## Scope (v1)
- Input: one YouTube URL (watch, youtu.be, shorts, embed, live) and an optional frame interval in seconds.
- Output: video title, channel, duration, timestamped transcript, extracted frames.
- Runs locally on `http://127.0.0.1:5000`. No API keys required.

## Stack
| Part | Tool |
|---|---|
| Server | Python 3, Flask |
| Video download | `yt-dlp` (low-res copy, max 480p) |
| Frame extraction | `ffmpeg` (bundled via `imageio-ffmpeg`) |
| Transcript | `youtube-transcript-api` |
| UI | Single static `index.html` (vanilla JS) |

## Files
- `app.py` — Flask server and extraction logic.
- `index.html` — the web page.
- `requirements.txt` — Python dependencies.
- `specs/v1.md` — this document.

## API
### `GET /`
Serves the web page.

### `POST /api/extract`
Request body (JSON):
```json
{ "url": "https://www.youtube.com/watch?v=...", "interval": 10 }
```
`interval` is optional (seconds between frames).

Response (JSON):
```json
{
  "video_id": "string",
  "title": "string",
  "channel": "string",
  "duration": 19,
  "interval": 5,
  "transcript": [{ "start": 1.2, "text": "..." }],
  "transcript_error": null,
  "frames": [{ "time": 0, "url": "/frames/<job>/frame_0001.jpg" }]
}
```
Errors: `400` for an invalid link, `502` if the video cannot be downloaded
(the transcript is still returned when available).

### `GET /frames/<job>/<name>`
Serves an extracted frame image.

## Behaviour
- Frame interval: if blank, about 40 frames per video with a minimum gap of 5 s.
  The interval is raised if needed so the total never exceeds 80 frames.
- Frames are scaled to 640 px wide JPEGs.
- The downloaded video is deleted after extraction; frames stay in `jobs/`.
- Only the 5 most recent jobs are kept on disk.
- Transcript language: English preferred, otherwise the first available track.
- If a video has no captions, frames are still returned with a `transcript_error` note.

## UI
- Link box, optional "Every N s" box, Extract button.
- Three views: **Timeline** (frame + words spoken until the next frame, with a link to that moment on YouTube), **Full text** (timestamped transcript with copy button), **Frames only** (grid).
- Light and dark theme follow the system setting.

## Out of scope for v1
- Describing frames with an AI model (e.g. via OpenRouter).
- Uploading to YouTube / OAuth.
- User accounts, queues, or hosting beyond localhost.
- Videos without captions are not transcribed (no speech-to-text).

## Run
```
pip install -r requirements.txt
python app.py
```
